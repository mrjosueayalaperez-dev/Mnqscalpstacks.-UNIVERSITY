How to study Phase I

  1. Go in order. Each module builds on the one before it — Module 1 first, Module 8 last.
  2. Do the practice exercise at the end of every module on a real chart before moving on.
  3. Take the knowledge check honestly. If you miss one, re-read the section — that's the point.
  4. Journal everything. Module 8 gives you the template; start using it from Module 1.
  5. No real money. Phase I is for learning. Simulation only, until a later phase says otherwise.

We do not promise profits.
We teach preparation, patience, accountability, and disciplined execution.
